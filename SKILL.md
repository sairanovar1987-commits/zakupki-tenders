# Поиск тендеров на zakupki.gov.ru (ЕИС)

## 0. Инструмент

- Только `browse` (реальный Chrome пользователя). Прямой `fetch`/`webfetch` отдаёт 403/анти-бот.
- Одна вкладка, последовательные переходы. Не открывать десятки вкладок и не делать параллельных запросов.
- Перед стартом: `browse.status`; если `connected:false` — передать пользователю `nextStep` и ждать.

## 1. URL поиска

```
https://zakupki.gov.ru/epz/order/extendedsearch/results.html
  ?morphology=on
  &fz44=on
  &af=on
  &customerPlace=<код региона>
  &sortBy=UPDATE_DATE
  &sortDirection=false
  &pageNumber=1
  &recordsPerPage=_50
  &applSubmissionCloseDateFrom=ДД.ММ.ГГГГ
  &orderIKZInputNameOkpd2=<4 цифры>
```

Параметры:

| Параметр | Значение |
|---|---|
| `customerPlace` | код региона, 11 цифр. Башкортостан — `02000000000`. Шаблон: `<код региона>000000000` (Москва `45000000000`, СПб `40000000000`, Татарстан `92000000000`). |
| `orderIKZInputNameOkpd2` | класс ОКПД2 без точки: `4120`, `4211`, `4321`. Работает только серверный GET-параметр. |
| `applSubmissionCloseDateFrom` | сегодняшняя дата — отсекает просроченные. |
| `af=on` | только актуальные. |
| `fz44=on` | 44-ФЗ. `fz223=on` добавлять только если нужны 223-ФЗ. |
| `recordsPerPage` | `_10`, `_20`, `_50`. |

Не работают (игнорируются): `selectedRegions`, `customerPlaceCodes`, `okpd2Ids*`. Модалка выбора ОКПД2 в UI сломана — не использовать.

## 2. Сбор списка

Классы ОКПД2 для строительства: `4120`, `4211`, `4221`, `4222`, `4291`, `4299`, `4311`, `4312`, `4313`, `4321`, `4322`, `4329`, `4330`–`4334`, `4339`, `4391`, `4399`. Минимальный рабочий набор: `4120, 4211, 4299, 4321, 4322, 4329, 4339, 4399`.

Цикл: для каждого класса открыть URL, собрать карточки со всех страниц (`pageNumber=1..N`, стоп когда 0 карточек или нет `.paginator-button-next`), дедуплицировать по `num`.

```js
// выполнить на странице результатов через browse.eval
(() => {
  const norm = s => (s || '').replace(/\s+/g, ' ').trim();
  return [...document.querySelectorAll('.registry-entry__form')].map(c => {
    const a = c.querySelector('.registry-entry__header-mid__number a');
    const block = title => {
      const b = [...c.querySelectorAll('.registry-entry__body-block')]
        .find(x => norm(x.querySelector('.registry-entry__body-title')?.textContent) === title);
      return b ? norm((b.querySelector('.registry-entry__body-href') || b.querySelector('.registry-entry__body-value'))?.textContent) : '';
    };
    return {
      num: (a?.textContent || '').replace(/\D/g, ''),
      href: a?.href || '',
      stage: norm(c.querySelector('.registry-entry__header-mid__title')?.textContent),
      name: block('Объект закупки'),
      cust: block('Организация, осуществляющая размещение'),
      price: norm(c.querySelector('.price-block__value')?.textContent).replace(/\s*₽$/, ''),
      dl: norm(c.querySelector('.data-block__value')?.textContent) // только дата, время — в карточке
    };
  });
})()
```

Прогресс складывать в `localStorage`: `__T_list` (номер + href + класс) и `__T_data` (полные записи) — переживает обрыв контекста.

## 3. Карточка извещения

Поля лежат в `.section__title` + `.section__info` (не в `innerText` — скрытые секции видны только в `textContent`).

```js
(() => {
  const norm = s => (s || '').replace(/\s+/g, ' ').trim();
  const sec = label => {
    const t = [...document.querySelectorAll('.section__title')].find(e => norm(e.textContent) === label);
    return t ? norm(t.closest('.blockInfo__section').querySelector('.section__info')?.textContent) : '';
  };
  const tb = [...document.querySelectorAll('table.blockInfo__table')].find(t => /Код позиции/.test(t.textContent));
  return {
    name:  sec('Наименование объекта закупки'),
    cust:  sec('Организация, осуществляющая размещение'),
    loc:   sec('Место нахождения'),
    place: sec('Место поставки товара, выполнения работы или оказания услуги') || sec('Место нахождения'),
    dl:    sec('Дата и время окончания срока подачи заявок').replace(/\s*\(МСК.*?\)/i, ''),
    price: sec('Начальная (максимальная) цена контракта') || sec('Максимальное значение цены контракта'),
    s1req: sec('Требуется обеспечение заявки'),
    s1:    sec('Размер обеспечения заявки'),
    s2req: sec('Требуется обеспечение исполнения контракта'),
    s2:    sec('Размер обеспечения исполнения контракта'),
    okpd:  tb ? [...tb.rows].slice(1).map(r => norm(r.cells[0]?.textContent)).filter(Boolean) : []
  };
})()
```

Правила:

- `name` может отсутствовать у отдельных типов — брать из списка.
- `place` — адрес объекта; `loc` — юр. адрес заказчика. В ответ идёт `place`, fallback `loc`.
- `cust` — «Организация, осуществляющая размещение». При централизованных закупках это уполномоченный орган (Госкомитет РБ, ГКУ РЦТ), а не конечное учреждение.
- Цена и срок надёжнее брать из списка: там они уже нормализованы (`3 222 218,07`), в карточке срок с часовым поясом.
- `s1/s2` приходят как `16 111,09 РОССИЙСКИЙ РУБЛЬ` или `30 %`:
  ```js
  const rub = s => (s.match(/\d[\d\s]*,\d{2}/) || [''])[0].trim();
  const pct = s => (s.match(/(\d+(?:[.,]\d+)?)\s*%/) || [])[1] || '';
  ```
  Вывод: сумма → `X ₽` (+ `(N %)` если есть); только процент → `N %`; `s2req === 'Нет'` → `не требуется`; секции нет → строку не выводить.

## 4. Анти-бот

Признак: `document.title` содержит `подозрительная активность` (страница отдаётся с кодом 200).

- Между переходами по карточкам пауза 1400–1600 мс (`browse.wait_for({tab, time:1500})`).
- Последовательно, не более ~1 карточки в 1.5 с. Параллельная загрузка ~70 страниц гарантированно ловит блок.
- При блоке: остановиться, подождать 3–5 минут, перезагрузить один раз. Не долбить.
- 223-ФЗ карточки имеют другой URL — брать `href` из выдачи, не конструировать.

## 5. Классификация

Фильтр ОКПД2 41/42/43 включает не только стройку. Исключать и отдельно считать:

- `Приобретение жилого помещения…` / `Приобретение жилых помещений…` — долевое строительство (обычно ОКПД2 `41.20.10.x`).
- `Оказание услуг`, `техническому обслуживанию`, `эксплуатационно-техническому обслуживанию`, `новогоднему оформлению` — обслуживание, не работы.

В ответе писать: «Не включены N закупок квартир и M контрактов на обслуживание — это не строительные работы».

## 6. Формат ответа

Сначала 1–2 строки: сколько всего, регион, дата, источник. Затем группировка `### ОКПД2 41.20 — капитальный ремонт зданий` и по каждому тендеру:

```
- 1. <полное наименование объекта закупки>
- Заказчик (краткое наименование): <орг>
- Место нахождения: <адрес объекта>
- Окончание подачи заявок: ДД.ММ.ГГГГ ЧЧ:ММ (осталось N дней)
- Цена контракта: 117 553 400,00 ₽
- Обеспечение заявки: 1 175 534,00 ₽
- Обеспечение контракта: 11 755 340,00 ₽ (10 %)
- Ссылка на документацию: https://zakupki.gov.ru/epz/order/notice/ok20/view/common-info.html?regNumber=...
```

- Строки обеспечений — только если есть данные.
- Остаток дней считать от текущей даты: `остался 1 день`, `осталось 2 дня`, `осталось 5 дней` (русская плюрализация).
- Сортировка: ОКПД2 → срок (по возрастанию) → цена (по убыванию).
- Выдавать **все** актуальные тендеры, не топ-N. Пользователь явно отвергает курированные подборки.
- Короткие наименования заказчиков сокращать по ОПФ (ГБУЗ, ГБОУ, МКУ, ГКУ, ФГБОУ ВО, АДМИНИСТРАЦИЯ…), кавычки — «…». Не выдумывать названия.

## 7. Грабли

- `customerPlace` — единственный работающий фильтр региона.
- `applSubmissionCloseDateFrom` обязателен, иначе в выдаче старые извещения.
- Один тендер может попасть в несколько классов ОКПД2 — дедуп по `num` (19 цифр).
- В списке `dl` без времени; время брать из карточки.
- У квартир цена может называться «Максимальное значение цены контракта».
- Проверять `stage === 'Подача заявок'`; снятые/отменённые не выводить.
- Валидация цены: `/^\d{1,3}( \d{3})*,\d{2}$/`.
